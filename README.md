# Special Junk Packet List 🛡️

**Генератор UDP-пакетов для обхода DPI в AmneziaWG.**

[Открыть генератор](https://voidwaifu.github.io/Special-Junk-Packet-List/)

## Что это?

Инструмент для генерации **Special Junk Packet** значений, которые помогают обходить системы глубокой фильтрации трафика (DPI) в VPN-подключениях через протокол **AmneziaWG**.

## Зачем?

Некоторые провайдеры используют DPI для блокировки VPN-трафика. Special Junk Packet маскирует VPN-подключение под обычный UDP-трафик (DNS, SIP и т.д.), что позволяет обойти блокировку.

## Как использовать?

1. Откройте **AmneziaVPN** (версия 4.8.8.1 или выше)
2. Перейдите: Настройки → Серверы → Ваш сервер → AmneziaWG → Настройки подключения
3. Скопируйте значение **I1** с этого сайта
4. Вставьте его в поле "I1 - Special Junk Packet"
5. Сохраните и попробуйте подключиться

Если не работает — пробуйте следующие значения (I2, I3...).
